# SQL Analysis

This folder contains SQL queries used to analyze customer shopping behavior and identify meaningful business insights using MySQL.

## Analysis Performed

The project includes 10 SQL business analysis questions:

1. **Revenue Analysis:** Compared total revenue generated by male and female customers.
2. **Discount Analysis:** Identified customers who used discounts but spent above the average purchase amount.
3. **Product Ratings:** Found the top 5 products with the highest average review ratings.
4. **Shipping Analysis:** Compared average purchase amounts between Standard and Express shipping.
5. **Subscription Analysis:** Compared average spending and total revenue between subscribed and non-subscribed customers.
6. **Discount Percentage:** Identified the top 5 products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Categorised customers into New, Returning, and Loyal segments based on previous purchases.
8. **Product Performance:** Identified the top 3 most purchased products within each category.
9. **Repeat Customer Analysis:** Examined subscription patterns among customers with more than 5 previous purchases.
10. **Age Group Analysis:** Analysed revenue contribution across different age groups.

## SQL Concepts Used

- Aggregate Functions (SUM, AVG, COUNT)

- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER, PARTITION BY)
