# Python Data Analysis

This folder contains the Jupyter Notebook used for data exploration, cleaning, preprocessing, and customer shopping behavior analysis using Python.

## Analysis Performed

- **Data Loading:** Imported the customer shopping dataset using Pandas.
- **Data Exploration:** Examined dataset structure, dimensions, column names, and data types.
- **Data Cleaning:** Checked for missing values, duplicate records, and data inconsistencies.
- **Data Preprocessing:** Prepared and organised data for further analysis.
- **Exploratory Data Analysis (EDA):** Explored customer demographics, purchasing patterns, product categories, and shopping preferences.

## Libraries Used

- **Python:** Programming language for data analysis.
- **Pandas:** Data manipulation and analysis.
- **NumPy:** Numerical operations and data processing.
- **Matplotlib / Seaborn:** Data visualization (if used in the notebook).

## Notebook File

`Customer_behaviour_Analysis.ipynb`

Open the notebook using Jupyter Notebook or JupyterLab to explore the Python analysis and code.

## Objective

To understand customer shopping behavior through data exploration and preprocessing, identify meaningful patterns, and prepare insights for further SQL analysis and Power BI visualization.
