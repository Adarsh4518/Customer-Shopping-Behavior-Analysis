# Power BI Dashboard

This folder contains the interactive Power BI dashboard developed for the Customer Shopping Behavior Analysis project.

## Dashboard Overview

The dashboard provides visual insights into customer shopping patterns, purchasing behavior, revenue performance, and customer demographics.

## Key Analysis Areas

- **Customer Demographics:** Analysis of customer age groups and gender distribution.
- **Revenue Analysis:** Understanding purchase amounts and revenue trends.
- **Product Analysis:** Exploring product categories and purchasing patterns.
- **Subscription Analysis:** Comparing subscribed and non-subscribed customers.
- **Shopping Behavior:** Analysing customer preferences and purchasing patterns.

## Tools & Technologies

- **Power BI Desktop:** Dashboard development and data visualization.
- **Power Query:** Data transformation and preparation.
- **DAX:** Measures and calculations.
- **MySQL:** Source database for customer shopping data.

## Dashboard File

`Customer_Behavior_Analysis_Dashboard.pbix`

Open the `.pbix` file using Power BI Desktop to explore the interactive dashboard.

This dashboard helps transform customer shopping data into meaningful visual insights to support data-driven business decisions.
