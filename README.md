
# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior using Python, Pandas, SQL (MySQL), and Power BI.

The objective is to explore customer purchasing patterns, identify key business trends, analyze revenue performance, and generate actionable insights to support data-driven decision-making.

## Tools & Technologies

- **Python:** Data exploration and analysis
- **Pandas & NumPy:** Data manipulation and preprocessing
- **Jupyter Notebook:** Python analysis
- **MySQL:** SQL queries and business analysis
- **Power BI:** Interactive dashboard and data visualization
- **GitHub:** Project documentation and version control

## Project Workflow

### 1. Python – Data Exploration and Analysis

- Imported the dataset using Pandas.
- Explored the dataset using `head()`, `info()`, and `describe()`.
- Examined column names, data types, and missing values.
- Performed data exploration and preprocessing using Python.

### 2. SQL – Business Analysis

Used MySQL to answer business-related questions, including:

- Revenue comparison between male and female customers.
- Customer spending patterns based on discounts.
- Top-rated and most-purchased products.
- Comparison of subscribers and non-subscribers.
- Customer segmentation into New, Returning, and Loyal.
- Revenue contribution by age group.
- Product discount analysis.

### 3. Power BI – Dashboard Development

Developed a Power BI dashboard to visualize customer shopping behavior, purchasing patterns, and business performance.

## Key Business Questions

1. Which gender contributes more to total revenue?
2. Do customers using discounts still spend above average?
3. Which products receive the highest average ratings?
4. Do subscribed customers spend more?
5. Which products have the highest discount percentage?
6. What is the revenue contribution of different age groups?

## Dataset Information

- **Dataset:** Customer Shopping Behavior
- **Total Records:** 3,900
- **Total Columns:** 18
- **Format:** CSV

The dataset contains customer demographics, purchased items, purchase amounts, product categories, discounts, subscription status, shipping information, and payment methods.
